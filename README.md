# إيوان للمطابخ والخزائن — الموقع الرسمي (Ewan Kitchens & Wardrobes)

واجهة رقمية تفاعلية لمصنع **إيوان للمطابخ والخزائن** — تصميم وتصنيع وتركيب المطابخ بهيكل PVC المقاوم للماء والرطوبة، الخزائن وغرف الملابس (الدريسنج)، غرف النوم، وأعمال الديكور الخشبي وCNC في جميع مناطق المملكة العربية السعودية.

## محتويات المشروع
- `index.html` — الصفحة الرئيسية التفاعلية (استوديو خامات الـ PVC، خطوات العمل، معرض الأعمال، أداة تغيير التشطيب، أداة تخطيط المطبخ، قائمة المقارنة، الأسئلة الشائعة، ونموذج الحجز).
- `services.html` — الخدمات الأربع وباقات المجمعات السكنية والمشاريع (`A / B / C`).
- `gallery.html` — المعرض التفاعلي الكامل (32 تصميمًا مصنفًا في 5 فئات + نافذة معاينة Lightbox).
- `about.html` — قصة المصنع، الرؤية والرسالة، القيم الأربع، وخطوط الإنتاج الآلية.
- `booking.html` — صفحة حجز موعد زيارة المصنع أو طلب استشارة عن بُعد.
- `contact.html` — قنوات التواصل المباشرة للأفراد والمشاريع والشركاء.
- `privacy.html` — الخصوصية والسياسات.
- `sitemap.xml` & `robots.txt` — ملفات الأرشفة ومحركات البحث.
- `assets/` — ملفات التنسيق (`styles.css`، `fonts.css`)، المنطق التفاعلي (`app.js`)، الخطوط المحلية، الشعارات، والصور المحسّنة للويب (`assets/web/`).
- `hero/` — مقاطع الفيديو الخلفية للهيرو بنسختَي سطح المكتب والجوال (`WebM` + `MP4`).
